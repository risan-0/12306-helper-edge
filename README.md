# 高铁出发 · Edge 购票助手 0.2.2

先用浏览器打开 guide.html。只作用于 12306 官方网页版，需自行登录、完成验证和付款。

## 安装与升级

下载code.zip压缩包，在本地解压。
解压后，在 Edge 打开 edge://extensions，开启开发人员模式，加载直接包含 manifest.json 的 rail-helper-edge 文件夹。无需 Python 或 Node.js。
升级前停止任务，覆盖原目录，在扩展管理页点击重新加载，关闭旧任务网页后重新启动。已发出的订单请求须先在官网检查。

## 最终确认生效检查

静音提示关闭后重新定位可见且未遮挡的确认按钮。点击后观察官网订单处理请求；等待 4 秒仍无请求且按钮可用时，重新核对行程、乘车人和席别后最多补点一次。已观察到订单处理请求则不重试；补点仍无响应时暂停并提示手动接手。只有进入官网支付页才显示完成。

## 静音提示确认修复

勾选静音后，自动识别静音车厢乘车说明，点击该窗口的“确定”，等待关闭和下层按钮可操作后，再点击核对信息的“确认”。也处理首次点击确认才弹出静音说明的页面。仅处理包含静音车厢、保持安静、耳机等具体内容的提示，不通用点击其他弹窗。检测到订单确认请求已发出时不再次确认。

## 功能

- 目标车次选填；留空匹配所选乘车日期与精确区间全部车次，按官网列表顺序选择。填写时按填写顺序优先，支持 G/D/C、K/T/Z 和数字车次。
- 可选席别：二等座、一等座、商务座、特等座、优选一等座、二等包座、高级软卧、软卧、动卧、高级动卧、硬卧、一等卧、二等卧、软座、硬座、无座、其他。每次只买所选的一种，不自动改买其他席别。
- 确认页默认 C/D 偏好，并在有可用静音车厢复选框时勾选后确认。也可选 A/F、单个字母或自动分配，并关闭静音偏好。
- 偏好位置不足以满足全部人数，或不支持选座时使用官网自动分配；不保留人数不足的部分选座。最终席位以铁路分配为准。
- C/D 是常见一/二等座过道位，其他车型请看官网座位图；卧铺上下铺不指定。
- 面板 − 缩小，× 隐藏；点击缩小按钮或扩展图标中的“显示网页面板”恢复。缩小和隐藏不会停止任务。
- 默认二等座、C/D 和静音优先。旧设置缺少新字段时采用这些默认值。
- 北京时间定时启动；单任务查询，默认每轮结束后等 15–16 秒；限流、验证、未知结果暂停。预订、提交各至多点击一次；确认仅在静音提示处理后或未检测到订单请求时允许受限补点。

## 演练与边界

取消自动提交可演练到选好乘车人和席别，不点击提交，因此不会到达后面的选座/静音确认弹窗。演练仍会查询和点击官网预订。
仅自动处理已保存并核验的成人乘车人，学生、儿童、优惠票、改签和中转需手动处理。
公开查询页和公开脚本中的选座容器已核对；完整流程用隔离 Edge 和模拟页面测试。未登录真实账户验证所有席别，未完成真实出票和节假日压力测试。不能保证抢到票、C/D 席位或静音车厢。
订单页依赖 ticketInfoForPassengerForm.orderRequestDTO 和预期的官方控件，不能可靠匹配会暂停。共用余票列的席别会在订单页再次按确切名称核对。
请保持网页前台、电脑联网且不休眠。停止扩展不能撤回已发请求，也不会取消订单。

## 数据与源码

行程、姓名和偏好仅在 Edge 本地保存，不云同步。任务和防重复记录存于浏览器会话内。不保存密码、证件号、Cookie 或支付信息，不向第三方上传数据。
core.js 是输入与席别目录；adapter.js 是网页适配；panel.js 是面板；content.js 是流程；background.js 是状态、锁和通知；popup.* 是设置。站名表为 2026-09-10 官方公开资源，3384 条记录。

## 开发者测试

日常使用不需要开发依赖。Node.js 22+ 执行：node --test tests/core.test.cjs tests/background.test.cjs
浏览器测试安装 Playwright 并使用 Edge，执行：node tests/browser.cjs
PLAYWRIGHT_MODULE 可指定模块路径，RAIL_TEST_WORK 可指定临时目录。测试使用独立配置，测试页 HTTPS 请求均被模拟或中止，不创建真实订单。详见 TEST-REPORT.md。
